## 4.1：长篇查找、论文资料卡、手机写作键

- 「全文查找」限当前小说，可按章节标题、正文、大纲筛选，结果能直接定位到对应稿件。
- 「稿件自检」是本机辅助：定位待完成标记、重复和较长段落，不改正文、不发网络请求。
- 论文资料卡可保存链接、书目信息和自己读过的笔记。链接与书目信息不代表查证过原文；提交前请逐条核对。只有主动选择参与 AI 的资料才用于模型提示，私人读书笔记不随请求发送。
- 窄屏有手动保存、写作常用标点和段落键。中、英、俄三语可以分别作为界面与作品输出语言。
- 本包可作为静态站部署；请确保 index.html、service-worker.js、manifest.webmanifest、css、js 和 icons 位于同一目录结构。换域名前先导出 JSON，浏览器中的稿件不会跨域自动迁移。


## 4.0：从第一份稿件开始

- 新手工作台指向小说、论文、模型和备份。可选择先在当前浏览器本地写作，不必创建账户。
- 小说先用「构思这一章」建立场景、目标、阻碍和转折；论文可用向导建立研究问题并核对数字引用。核对格式并不证明文献支持论点。
- AI 模型可以选内置、云端预设或本机兼容接口。真实模型仍需访问对应服务，服务可能有独立的额度、密钥和网络要求。
- 「设置 → 备份与导出」可下载 TXT、可编辑 DOCX 或带版本历史的 JSON。JSON 恢复为独立副本。
- 在安全的 HTTPS 地址或 localhost 首次在线打开以缓存界面；此后可离线手写和管理稿件。安装入口在设置里，浏览器是否提供主屏幕安装以设备为准。AI、在线文献和词典仍需联网。
- 写作数据和备份都属于当前浏览器或下载文件，不做设备同步。换域名、浏览器或设备前，先导出 JSON。

## 🚀 快速开始

1. 双击 `index.html`，用 **Chrome / Edge** 打开即可（纯本地运行，无需服务器、无需安装；手机/平板/电脑全设备自适配，小屏自动变为上下布局并支持整页滚动）。
2. 点右上「👤 个人档案」设置头像与昵称。
3. 点击顶部书名 →「＋ 新建小说」→ 在**风格表格**里选用户群体、类型、篇幅、视角、基调、写作语言与参考作家。
4. 新建章节 → 在「📋 本章大纲」输入本章大纲 → 点「⚡ 联网生成正文」，坐等正文流式写出；不满意点「🔄 重新生成」。
5. 点右上「⚙ 设置」集中管理：字号、**界面样式（小框大纲大框正文 / 一半大纲一半正文）**、AI 面板开关、主题色、账户、语言、备份、AI 接入、反馈、用户须知、版本更新。

> 想部署成真正的网站？把整个文件夹扔到任意静态服务器即可（Nginx / GitHub Pages / Vercel 等），零构建。

## ⚡ 章节大纲 → 联网生成正文（核心流程）

1. 在编辑器上方「📋 本章大纲」大输入框里写下本章大纲（发生什么、出场人物、伏笔…）。
2. 点击「⚡ 联网生成正文」，右下角出现**实时进度卡**，依次执行：
   - ✓ **正在搜索作家**：联网抓取参考作家的维基百科资料（已缓存则跳过）
   - ✓ **正在学习作家文风**：整理内置技法 + 联网资料
   - ✓ **正在拟写正文**：AI 先产出本章细纲（核心一句话 / 情节节点 / 开头钩子）
   - ✓ **正在输出正文**：正文实时流式写入编辑器
3. 对结果不满意？点「🔄 重新生成」即可重来（会覆盖当前正文，生成前有确认）。
4. 免费模型偶发繁忙/限流时会**自动延时重试**（最多 3 次），进度卡上会显示重试倒计时。

## 🌐 部署到 GitHub Pages（免费，可被搜索引擎收录）

1. 注册 [GitHub](https://github.com) 账号（免费，1 分钟）。
2. 右上角 `+` → **New repository**，仓库名填 `xiaoxing`（或其他名字），选 **Public** 公开仓库，创建。
3. 进入仓库页 → **Add file** → **Upload files** → 把本项目文件夹里的文件全部拖入（index.html、css/、js/、og-image.png、robots.txt、sitemap.xml 等）→ **Commit changes**。
4. 仓库页 → **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → 分支选 `main`、目录选 `/ (root)` → **Save**。
5. 稍等 1-2 分钟，页面会显示你的网址：`https://你的用户名.github.io/xiaoxing/`。
6. 把 index.html 里 `<link rel="canonical">`、`og:url`、`og:image`、JSON-LD 中的域名，以及 robots.txt、sitemap.xml 里的域名，替换成你的 github.io 网址后重新上传（Commit）。
7. （可选）用同一邮箱注册 [Google Search Console](https://search.google.com/search-console)，添加该网址并提交 sitemap.xml，加速收录。

### 本地开源模型（完全免费）

**Ollama**（推荐，中文写作可选 `qwen2.5` 系列）：

```powershell
# 1. 安装 https://ollama.com 后拉取模型
ollama run qwen2.5:14b

# 2. 允许浏览器跨域（设置后需重启 Ollama）
setx OLLAMA_ORIGINS "*"

# 3. 网站里 Base URL 填 http://localhost:11434/v1
```

**LM Studio**：加载模型 → 启动本地服务器（端口 1234），Base URL 填 `http://localhost:1234/v1`。

**CORS 代理**（云端或本地模型被浏览器拦截时使用）：

```powershell
node proxy.mjs                                        # 转发到 Ollama
node proxy.mjs 8787 https://api.deepseek.com          # 转发到云端 API
```

启动后 Base URL 填 `http://localhost:8787/v1`。

## 🧠 记忆机制（AI 如何“记住”你的小说）

每次与 AI 对话时，系统自动组装上下文注入：**小说信息 → 风格档案 → 参考作家技法 → 大纲 → 角色卡 → 世界观 → 记忆库 → 前文章节 → 当前章节**。范围可在 AI 面板「上下文注入 · 记忆范围」开关。

想让 AI 记住新内容：直接说「记住：××× 的右臂是机械臂」，或点「◬ 提取记忆」让 AI 读章节后自动产出记忆条目并一键入库。

## ❓ 常见问题

| 现象 | 解决 |
| --- | --- |
| 报 `Failed to fetch` / CORS | 本地模型请确认已启动；Ollama 需 `OLLAMA_ORIGINS=*`；仍不行就用 `node proxy.mjs` 代理 |
| 报 404 | 检查 Base URL 是否以 `/v1` 结尾、模型名称是否拼写正确 |
| 报 401/403 | API Key 错误或未填 |
| 报 429 | 限流或额度不足，稍后再试 |
| 文风学习失败 | 联网功能需要网络；失败不影响使用，内置技法仍会注入 AI |
| 词典查不到 | 该接口需联网；检查拼写或换个词 |
| 想换字体/更多风格 | 打开 `css/style.css` 修改 `--font-ui` 等变量即可 |
